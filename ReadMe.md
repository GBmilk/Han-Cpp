# 汉++ Han++

#### 一个中文版的C++

*作者：GB牛奶*

## 简介

**Han++** 是一个基于 C++17 的**中文语法头文件库**。它通过类型别名、内联函数和宏，把 C++ 的基础语法、标准容器、数学运算、字符串处理、数组操作全部“汉化”，让你可以用**接近自然语言的中文**编写 C++ 程序。

✨ 特性
----

* 🀄 **全中文语法**：`如果`、`否则`、`循环`、`当`、`类`、

* 🧩 **标准库封装**：类型、容器、IO、数学、字符串、数组全部中文别名

* 🖥️ **自动 UTF-8**：Windows 下自动切换控制台代码页，中文不乱码

* 🌍 **跨平台**：MSVC / GCC / Clang 全支持，Windows / Linux / macOS 通用

* 🚀 **零依赖**：只依赖 C++ 标准库

### 三、输入输出

| 函数            | 说明          | 示例              |
